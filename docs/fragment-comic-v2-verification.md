# 故事碎片 ComicDocument v2 验证记录

日期：2026-08-31。范围：Grapery、grapery-agent、Voyager 当前工作区；未部署、未提交。

## 本轮已修复

- 分格生图比例按「归一化格子尺寸 × 整页像素尺寸」计算，支持横竖页，避免错误裁切。
- 漫画页合成失败不再静默退回整页生图；失败资产保存在任务场景中，渲染器可复用已有格子。纠错重绘不复用问题格子的图片。
- 生成每格之前检查取消状态；合成器拒绝无效矩形、超大文件和超大解码尺寸。
- 文档创建、续写、替换、旧稿迁移不再通过共享切片修改原来的对白 ID/渲染方式。
- 没有图片的页不再标为「已渲染」；旧版整页位图不再重复叠加对白。
- 按页码而不是数组位置替换稀疏历史页；续写前根据当前图片列表剔除已删除页并重新编号。
- 客户端按图片身份关联对白，删除前页、调序或撤销不会套用另一页对白。
- Agent 的生成中快照公开漫画文档；后端逐页更新图片、状态及对白文档，供后台恢复使用。
- 预览与导出共用文字位置换算，修复 `upper_center` 被放到竖直中间。
- 发布从无字背景合成，避免重试重复叠字；背景下载失败时停止发布，不再悄悄发布缺对白图片；导出不再随设备屏幕倍率放大像素尺寸。
- 将遗漏的 `voyagerTests` 加入共享测试方案；更新失效的枚举/登录路由测试，允许测试关闭自动恢复会话以避免模拟器自动登录干扰。

## 仍需继续补齐/验收

1. 真实 Seedream + OSS 的整页生成、角色一致性、中文阅读质量与耗时/费用验收。本轮合成测试使用本地 HTTP 图片夹具，不调用付费图片模型。
2. 跨任务逐格续传：本轮实现的是渲染器的格子资产复用和任务结果保留；客户端「只重试剩余图片」仍新建任务，尚不能保证跨任务复用原分镜及格子资产。
3. 文字图层高级表现：气泡尾巴绑定人物、心理气泡、喊叫气泡、强调字及多个气泡的避让，需要进一步统一预览和导出渲染器。
4. Agent 审稿闭环：当前有分镜修订与 directorReview 诊断，但诊断不通过还不是完整的阻断/再次修订闭环。
5. 版式仍主要按动态格数构建确定性布局；按剧情重要性决定跨栏、大格和非均匀构图的能力需要扩展。

因此，本轮结果是稳定性修复和可执行回归基线，不是对「稳定专业漫画成品」的最终验收。
