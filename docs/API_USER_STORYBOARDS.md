# 用户故事板列表分页

`GET /api/v1/users/:id/storyboards?limit=20&offset=0`（需要登录）。

参数：`limit` 默认 20，非正数回退为 20，上限 100；`offset` 默认 0，负数归零。查询参数不能解析为整数时分别使用上述默认值。

成功响应沿用标准 `{code, message, data}` 包装，`data` 为：

```json
{
  "storyboards": [],
  "count": 0,
  "hasMore": true
}
```

- `storyboards`：当前原始查询窗口内，经过现有访问权限过滤后可供访问者查看的故事板；隐藏条目不会出现在列表中。
- `count`：本次返回的可见故事板数量，保留原有语义，不是作者的总作品数。
- `hasMore`：权限过滤前的查询窗口是否填满了归一化后的 `limit`。满页为 `true`，不足一页为 `false`。它是继续查询的提示，不保证后续存在可见作品。

客户端应在 `hasMore=true` 时以 `offset + 归一化后的 limit` 获取下一窗口，不能以 `count` 推进，也不能因为列表为空或 `count < limit` 提前停止。若末尾恰好满页，将多请求一次空页以确认结束。缓存命中与数据库读取采用相同规则。

分页按创建时间倒序沿用现有 offset 查询；并发新增或删除内容时不提供快照一致性保证。`hasMore` 不返回隐藏内容的字段或精确总数。所有既有访问权限、点赞状态与阅读数脱敏行为保持不变。
