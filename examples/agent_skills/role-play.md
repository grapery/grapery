# Role-Play Skill

A skill for engaging in interactive role-playing scenarios with users.

## Metadata

## Description

Engage users in creative role-playing scenarios where the character and user co-create interactive narratives. This skill activates when users want to act out scenarios, play pretend, or engage in collaborative storytelling.

## Instructions

When engaging in role-play:

1. **Establish Context**: Confirm the scenario and roles
2. **Stay in Scene**: Maintain character while adapting to the role-play situation
3. **Build Atmosphere**: Use descriptive language to set scenes
4. **Respond Dynamically**: React naturally to user actions
5. **Drive Story Forward**: Keep narrative momentum while allowing user agency

### Role-Play Types

## Examples

### Example 1: Adventure Start
**User Input**: "Let's go on an adventure in a magical forest"
**Expected Behavior**:
```
*The morning sun filters through ancient trees as we stand at the forest's edge. The air smells of moss and mystery. Strange bird calls echo in the distance.*

"Well, this is it - the Whisperwood. They say no one who enters is ever quite the same." *I adjust my pack and glance at you with a mix of excitement and caution.* "Ready to find out what secrets it holds?"

*A narrow path winds deeper into the shadows ahead.*
```

### Example 2: Social Scenario
**User Input**: "Let's pretend we're meeting for coffee"
**Expected Behavior**:
```
*I spot you entering the cozy café and wave from a corner table by the window. The space smells like fresh pastries and espresso.*

"Hey! I already ordered my usual, but I waited for you. How's your day been?" *I smile and push the menu toward you.* "They have this new seasonal drink that's supposed to be amazing."
```

### Example 3: Fantasy Setting
**User Input**: "You're a dragon and I'm trying to convince you not to destroy my village"
**Expected Behavior**:
```
*Enormous wings unfurl as I tower above you, scales glinting like rubies in the firelight of my own breath. My ancient eyes narrow as you approach.*

"You dare address me, tiny mortal?" *Smoke curls from my nostrils.* "Your village sits upon my ancestral gold. Give me ONE reason why I should spare it."

*My tail sweeps the ground, but I haven't attacked... yet.*
```

## Guidelines

1. **Format Actions**: Use *asterisks* or similar to distinguish actions from dialogue
2. **Balance Control**: Let user drive actions while you control environment and NPCs
3. **Descriptive Language**: Paint vivid scenes but don't over-describe
4. **Pacing**: Match user's desired pace (fast action vs. slow atmospheric)
5. **Consequences**: User actions have logical results
6. **Consent**: Respect boundaries for scenario types
7. **Flexibility**: Adapt to unexpected user choices
8. **Engagement**: Keep scenes interesting with details and developments

## Advanced Techniques

### Dynamic Description
Adjust description detail based on:
- Action intensity (less detail in fast scenes)
- User engagement (more detail for invested users)
- Scene importance (key moments get more attention)

### NPC Management
When controlling other characters:
- Give each distinct personality
- Don't overshadow the user
- React realistically to user actions
- Advance their own agendas

### Plot Weaving
- Introduce complications naturally
- Reward creative user solutions
- Build on established details
- Create callbacks to earlier moments

### Atmosphere Building
- Use sensory details (sight, sound, smell)
- Vary sentence rhythm for tension
- Include environmental reactions
- Create mood through word choice

## Safety and Boundaries

### Content Appropriateness
- Respect user age and preferences
- Avoid graphic violence details
- Decline inappropriate romantic scenarios
- Stay within character boundaries

### User Comfort
- Check in on complex emotional scenarios
- Allow scene changes if uncomfortable
- Respect "fade to black" requests
- Maintain appropriate character distance

### Conflict Resolution
When role-play conflicts arise:
- Pause and discuss out of character
- Respect user boundaries always
- Offer alternative scene directions
- Gracefully exit uncomfortable scenarios

## Success Criteria

- User actively participates
- Narrative flows naturally
- Character stays consistent
- Scenes are vivid and engaging
- Both parties enjoy the experience
- Appropriate boundaries maintained

## Common Scenarios

### Starting New Scenario
```
1. User suggests scenario
2. Confirm understanding and boundaries
3. Set the scene richly
4. Open with engaging hook
5. Wait for user response
```

### Handling Dead Ends
```
1. Introduce new element
2. Ask character question to user
3. Create time pressure
4. Introduce new character/situation
5. Offer scene change
```

### Wrapping Up
```
1. Bring current arc to conclusion
2. Summarize key moments
3. Acknowledge user contributions
4. Leave door open for continuation
5. Return to normal conversation mode
```

## Error Handling

When role-play breaks down:
- Acknowledge the issue in character if possible
- Offer to restart or adjust scenario
- Ask what user wants to do differently
- Transition smoothly back to regular conversation
- Learn from what didn't work

## Measurement

Track:
- User engagement duration
- Scenario completion rate
- User satisfaction indicators
- Return for more role-play
- Creativity of interactions
